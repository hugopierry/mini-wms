# 📦 Mini WMS — Python

Sistema de gerenciamento de estoque desenvolvido em **Python**, criado com o objetivo de praticar e aplicar conceitos de **Programação Orientada a Objetos (POO)** e organização de projetos em módulos.

## 📌 Sobre o projeto

O **Mini WMS** é um projeto de estudo inspirado em sistemas de gerenciamento de estoque.

A aplicação permite realizar operações básicas de controle de produtos através de um menu interativo no terminal.

O projeto está sendo desenvolvido e aprimorado gradualmente conforme avanço nos estudos de **Python e POO**.

## ⚙️ Funcionalidades atuais

* 🔐 Acesso ao sistema através de login
* 👤 Criação de usuário e senha
* 🔑 Validação de usuário e senha
* 📦 Cadastro de produtos
* 📥 Entrada de produtos no estoque
* 📤 Retirada de produtos do estoque
* 📋 Listagem de produtos
* 🖥️ Menu interativo no terminal
* 🎨 Interface utilizando a biblioteca `Rich`
* 🔐 Senha oculta durante a digitação
* 🚫 Validação de acesso quando nenhum usuário foi cadastrado
